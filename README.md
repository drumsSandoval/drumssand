# drumssand

**Oscar Sandoval — Creative Developer.**

I live with ADHD. My head is loud — noise, color, music, fashion, code, all at once.
Instead of fighting it, I turned it into a canvas. This site is what it looks like from in here.

No frameworks, no build step. One HTML file, p5.js, and a random sketch on every load:

| Sketch | What you're seeing |
| --- | --- |
| `adhd_wave` | Mental noise, raw. Glitch, shake, static. |
| `the_wall` | A wall of counted days. Hit it — fall into pain, another era, or an acid trip. It always rebuilds. |
| `garden` | A hallucinatory paradise that melts forever and never lets you leave. |
| `cloth` | A textile floating in zero-g. Bowie woven in — the bolt, Ziggy, Major Tom. |
| `draw_flow` / `hard_noise` / `paint` | Light, glitch, and brushstrokes — the quieter corners of the same mind. |

Built by hand, tuned by eye. Reload for a different state of mind.
